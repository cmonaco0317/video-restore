# Test fixture credits

`clean.png`, `lowbitrate.png`, `darkrip.png`, `lr_clean.png`, `lr_compressed.png`

These are frames from **Tears of Steel** (2012), **(CC) Blender Foundation |
mango.blender.org**, used under **CC BY 3.0**.

  https://mango.blender.org/

They are the ground-truth pairs the whole test suite is judged against: one clean
plate and several deliberately degraded versions of the same frame. Every quality
number in this project — every dB figure in `STATE.md`, every before/after in
`test/compare.html` — is a measurement taken on this film.

**If you copy these files, or publish an image made from them, the attribution
goes with you.** That includes screenshots of the comparison page, which are
pictures of the film rather than of the code.

See `../THIRD-PARTY.md` for the full picture.
